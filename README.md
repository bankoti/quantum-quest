# Quantum Quest

A visual, interactive course for learning quantum physics from first principles. The first release includes a 35-lesson roadmap and one complete mobile-friendly journey through scale, wave-particle duality, the double-slit experiment, probability, and measurement.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
npm run smoke
```

The site deploys to GitHub Pages from `main` through [the deploy workflow](.github/workflows/deploy.yml).
